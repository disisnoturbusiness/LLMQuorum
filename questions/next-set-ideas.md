## New category: Decoys ("can it ignore the noise?")
Owner decision 2026-09-18. Five questions: the hourly-rate question carries over from set v2, plus four new ones.
Each has one irrelevant detail that a payroll or tax person ignores without thinking. All keys are arithmetic, so anyone can check them with a calculator.
Why: on set v2's hourly-rate question, 20 of 41 models took the "biweekly" bait ($134.62 = one check / 40 hours, $53.85 = one check / 100 hours, $26.92 = one check / 200 hours).
